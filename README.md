# Audit Service

Микросервис для аудита действий пользователей.

Сервис принимает события пользователей, сохраняет их в PostgreSQL,
надёжно доставляет в Kafka через Outbox Pattern и строит статистику
по событиям, прошедшим через Kafka.

## Стек

- Go
- PostgreSQL
- Apache Kafka
- Docker Compose
- kafka-go
- pgx
- Swagger
- Testcontainers

---

## Основной поток события

Например пользователь выполнил действие:

```json
{
  "user_id": "123",
  "action": "login",
  "resource_id": "site",
  "meta": {}
}
```

## Настройки Kafka

- `KAFKA_TOPIC` — топик событий, по умолчанию `user-actions`.
- `KAFKA_GROUP` — группа потребителей, по умолчанию `analytics-group`.
- `KAFKA_COMMIT_INTERVAL` — интервал отправки подготовленных оффсетов, по умолчанию `5s`.
- `KAFKA_READ_MAX_BYTES` — максимальный размер пакета чтения в байтах, по умолчанию `10485760` (10 МиБ).

Consumer передаёт оффсеты на коммит только после успешного сохранения
статистики. При ненулевом интервале коммит выполняется асинхронно;
ошибки Kafka выводятся отдельно с префиксом `[kafka-error]`.
При интервале `0s` вызов `CommitMessages` ожидает результат коммита.

`POST /api/audit` сохраняет событие и задание outbox одной транзакцией,
затем ждёт доставки. Ответ `201` возвращается только после подтверждения
Kafka (`RequiredAcks=RequireAll`) и сохранения статуса `sent` в outbox.

`AUDIT_PUBLISH_TIMEOUT` ограничивает ожидание доставки (по умолчанию `30s`).
Если подтверждение не получено вовремя, API возвращает `503` с полями
`event_id`, `timestamp`, `error`. Событие уже сохранено и worker продолжает
доставку; повторный POST создаст новое событие, поэтому автоматически
повторять его после такого ответа не следует.

## Проверки

При запущенном Docker:

```bash
go test ./... -count=1 -timeout=5m
go vet ./...
```

Интеграционные тесты поднимают отдельные временные Kafka и PostgreSQL.
Они проверяют доставку от producer к consumer, ожидание подтверждения в API,
сохранение события при таймауте, историю и статистику, а также replay
с повторным пересчётом без удвоения результата. В тесте интервал аналитики
сокращён; стандартный интервал приложения остаётся равным пяти минутам.
